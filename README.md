# ALFA Ships

A compact static shipping site for ocean freight, project cargo, and shipment tracking.

## Structure

The active site is intentionally limited to four files:

- `index.html` — the public landing page, quote form, tracking form, and contact details
- `style.css` — the single local stylesheet for the site
- `script.js` — lightweight quote and tracking interactions
- `README.md` — project notes

User-management flows such as login, registration, and dashboards are not part of the public site.
